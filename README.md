# Personal Web Application & Research Portfolio

A modern, high-performance web application designed to showcase computational research, data science projects, and peer-reviewed literature.

## Technology Stack

- **Framework:** Next.js (App Router, Static HTML Export)
- **Styling:** Tailwind CSS
- **Deployment:** GitHub Pages (Automated CI/CD via GitHub Actions)

## Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build static production export:**
   ```bash
   npm run build
   ```
